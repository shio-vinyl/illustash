关于这页：是什么，怎么用

census.js 过期了。样式（app.css、css/）和统计时不同，令牌表是旧的。重新运行 python3 tools/styleguide/census.py（python3 tools/check_styleguide.py 也会报出这一条）。

给人看：设计是否统一，一眼比较。给代理看：写新界面前先在这里找现成的写法，复用，不要自己造新类名、新数值。找不到合适的，先在 Issue 里问（见 AGENTS.md）。

样式是真的：页面直接引用 web/static/css/tokens.css、app.css 和 css/base.css，没有第二套 CSS。结构分两种，每个条目标题旁都标了是哪种：

调用生成 由 live.js 直接调用 web/static/ui/*.js 里生成组件的函数画出来，和应用里一模一样，不会和代码脱节：全部对话框（openDialog 上的 7 个，加命令面板、关系对比 / 按相似细分、快捷键帮助）、视图选项、作品弹层、任务面板、toast、选择栏、提问条。应用页面里写好的外壳（#toast、#picker…）从 web/static/index.html 原样取来；要读接口的，由 live.js 里的桩回答合成数据。生成之后克隆一份摆进页面，所以是静态的：点了不会做什么。产品代码改了、样例画不出来时，舞台里会写明原因。

手写 没有可以单独调用的生成函数（按钮、输入、芯片这些散落在各模板里的写法，标签弹层、更多菜单、详情栏、侧栏、顶栏、图片卡、设置卡、引导、查看器、海报），HTML 是对着模板手抄的；“来源”一栏写了文件和函数名，改模板时回头对一下。

有检查兜底：tools/check_styleguide.py（接在 tools/check_all.sh 和 CI 里）要求样例和条目标题用到的每个类都在 app.css 里有样式、census.js 和当前 app.css 一致；live.js 导入的每个函数在 web/static 里确实导出、要取的外壳 id 还在、每个舞台都有对应的样例，每个条目都标了来源。改名或删掉一个类或函数、改了 app.css 没重跑统计，都会报出具体的位置和改法。它查不出手写样例的结构和模板不一致，这一点仍要靠“来源”一栏人工对照。

怎么打开：在仓库根目录运行 python3 -m http.server 8000，再打开 /tools/styleguide/：调用生成的样例要这样才看得到（浏览器不从 file:// 加载 ES 模块），页面也会检查令牌统计是否过期。直接用浏览器打开本文件（file://）也行，只是只有令牌表和手写样例。顶部可切换亮色 / 暗色，和应用里的 html[data-theme] 是同一个机制。

不进发布包：packaging/build.py 只复制 web/static/，本页在 tools/styleguide/，不会被打进去；迁移清点（tools/migration_inventory.py）也把这个目录当开发工具，不算生产代码。

浮层怎么摆在页面里：应用里的 toast、选择栏、任务面板、弹出菜单是 position:fixed/absolute，对话框要 showModal()。这里用 .sg-frozen 把定位和入场动画关掉（styleguide.css 里每条一行），其余样式不动；对话框是不经 showModal() 打开的 <dialog open>，所以没有遮罩。

数字的口径：令牌表由 census.py 从 app.css 和 css/ 下的文件数出来：令牌的“引用”是 var(--名字) 出现的次数；“档位之外”的取值是一处 = 一条规则里的一条声明，取值只做 !important / 0.5→.5 的规范化，不合并相近的取值。。按钮写法的次数是 ui/*.js 与 index.html 里字面的 <button class="…"> 个数（2026-11-12 的 main），动态拼出来的类名不在内。

令牌 · 颜色

颜色变量写在 css/tokens.css 开头的 :root 里，按用途分组；暗色在 :root[data-theme=dark] 里成对换值。规则里只引用变量，不写十六进制色，暗色就不用再单独覆盖。新颜色先找现成的一组；确实没有，在两个块里成对加一个变量。

语义色（亮色 / 暗色并排）

--canvas--sheet--ink--tone-*--atag-*…

定义：web/static/css/tokens.css 开头的两个主题块，分组标题就是块里的注释；切换：web/static/theme.js 设置 html[data-theme]。色块用各自主题的变量画（两栏各自带一套变量值），后面的数字是 var(--名字) 在样式里被引用的次数。

基础一组的用法：画布 --canvas（页面底）→ 纸面 --sheet（内容区、卡片、浮层）→ --soft（控件底、占位）；文字 --ink / --ink2 / --muted / --faint 由深到浅；--line 实线分隔，--hair 是半透明发丝线（卡片轮廓、阴影的 1px 环）；强调色 --accent（环、勾、进度）、--accent-btn（按钮底，更深）、--accent-soft（选中底）、--accent-ink（强调色文字）；--warn 警示；--r18 / --r18-soft 仅用于 R18 开关。色调 --tone-*-bg / --tone-*-ink 成对用；--ok / --bad / --err 不随主题变。

非颜色的变量

主题块里不是颜色的变量，以及只在局部定义或由 JS 内联写入的自定义属性：--gutter（.content 上，26px；≥1600px 36px；≤1050px 16px；≤760px 12px）、--dup-hue（ui/grid.js 内联）、--p（最近 30 天的圆环，ui/catalog.js 内联）、--depth（作品树缩进，ui/catalog.js 内联）。--panel 在 .aa-card 里被引用（带回退值），但从未定义过。

写死的颜色（没走变量）

存量，不要照抄

这些颜色不会随主题自动换。新代码不要再写；改到附近的规则时顺手换成变量。

令牌 · 字号

正文字号是 --fs-N 一组档位，展示字号（大标题、空状态、启动页等一次性的大字）另有 --fs-display-N，不进正文档位。名字里的数字就是 px 值；新写的值取最近的一档，不要再写档位之外的数。基础字号是 :root 的 var(--fs-13)，用得最多的是 12 和 11。

正文字号

--fs-10…--fs-22

展示字号

--fs-display-17…--fs-display-72

档位之外的写法

口径：font-size 声明与 font 简写里的字号，去掉整条只用令牌的。

令牌 · 圆角

圆角档位

--radius-N--radius-pill--radius-round

小块是 44px 方块上的实际效果。胶囊形（按钮、芯片）用 --radius-pill，圆形（头像、圆点）用 --radius-round。

档位之外的写法

口径：border-radius 与四个单角写法的声明，去掉整条只用令牌（或 0）的。

令牌 · 间距

间距档位

--space-1…--space-24

gap 和 padding 共用一组 --space-N。“样子”画的是两个相邻的块，中间隔开这个宽度。

gap：档位之外的写法

口径：gap / row-gap / column-gap 的声明，去掉整条只用令牌（或 0）的。

padding：常见组合与档位之外的写法

令牌 · 控件高度

控件高度三档

--h-28--h-32--h-36

--h-N 只用于按钮、输入框、下拉等控件的高度；头像、缩略图和图标底板的尺寸不在其内。

其余固定高度

口径：height / min-height 里写 px 的声明（百分比、auto、0 不数）。这里多是图片区、缩略图、进度条和设置行，不是控件；只列出来供对照。

令牌 · 层级

z-index 档位

--z-*

由低到高：页面内局部叠放 --z-page-N < 浮动条 < 浮层 < 抽屉 < 菜单 < 全屏浮层 < 提示条 < 引导 < 启动页。只能新增档位，不要改数值的先后（css/tokens.css 里的约定）。

toast（--z-toast）压在查看器（--z-overlay）上，所以看大图时 toast 要移到中下方（body.viewing .toast）。引导的清单、提示条比选择栏高。

令牌 · 字重、阴影、动效、图的颜色（0.4）

0.4 的视觉语言（#685、#705）新加的令牌，定义在 web/static/css/tokens.css，亮暗成对写。新代码只用这里的三档；tools/check_frontend.py 规则 13 拦三档以外的字重、阴影、时长和缓动，以及新代码不该用的字号、圆角档位。新写的界面字号只用 11 / 12 / 13 / 20（--fs-N）和 28 / 40（--fs-display-N）；圆角只用 4（40px 以下的小元素）/ 8（缩略图、格子）/ 12（卡片、分组、弹出层）/ 18（内容页、对话框、活页条标签），加胶囊（能点的控件）和圆形（人），嵌套时内层 = 外层 − 间距；2 / 6 / 10 / 14 / 16 只留给旧样式。

字重三档

--fw-400--fw-600--fw-750

正文；强调和节标题；展示字号。Windows 的微软雅黑只有常规和粗体两档，600 和 750 都画成粗体。

阴影三档

--shadow-hover--shadow-pop--shadow-dialog

只给浮起来的东西：悬停；弹出层；对话框。暗色另有一套。不带模糊的描边环（0 0 0 2px var(--accent)）不算阴影，照写。放在 .tint 里的元素，悬停阴影带上图的颜色（最右一块）。

动效：时长三档、缓动两条

--dur-1--dur-2--dur-3--ease--ease-spring

140ms：出场、悬停；240ms：进场、展开、换页；380ms：共享元素、活页条标签。出场比进场短。--ease 给所有进出场、展开、换页；--ease-spring 带回弹，只给活页条标签和「弹一下」。系统开了「减少动态效果」时三档时长都是 0。脚本里的动画走 web/static/ui/motion.js（用法写在文件开头）。点「播放」看每一档。

图的颜色：--tint 和派生的底色

--tint--tint-wash--tint-soft--tint-glow--tint-shadow.tint

颜色只用、不展示：图的主色只经 web/static/ui/tint.js 的 setTint(el, color) 写，它写 --tint 并给元素加 .tint，派生的几档在那个元素上用 color-mix() 重新算（自定义属性里的 var() 在声明它的元素上就算好了）。wash：作品卡、日历格的底；soft：缩略图读完之前的占位；glow：环境光；shadow：悬停的彩色投影。没写 --tint 时是中性色（第一列）。下面的色值是样例，界面上不出色块、色值。
